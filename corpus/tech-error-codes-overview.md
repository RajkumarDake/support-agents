# Reading our error codes
Every error surfaced in the product carries a code of the form ERR_NNNN. The first digit tells
you the family: 1xxx authentication, 2xxx permissions, 3xxx validation, 4xxx rate limiting,
5xxx storage and uploads, 6xxx integrations and webhooks.

Quote the full code and the timestamp when you contact support. Codes are also written to the
audit log, which Admins can export.
