# Checking your plan and usage
Settings > Plan and usage shows the current plan, the renewal date, seats used against seats
included, API calls this period, and storage consumed.

Usage resets at the start of each billing period. At 80% of any limit we email the Owner; at
100% the affected feature is soft-capped rather than cut off, and API calls begin returning
ERR_4029 until the period rolls over or the plan is raised.
